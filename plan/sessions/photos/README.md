# Photos for the run sheets

Drop a `.png` file in here. A session file puts it on its sheet with a normal markdown image line, the same way it points at a generated diagram:

```
![The first step out of a start, from the side](../photos/first-step.png)
```

The alt text becomes the caption under the picture. The build does not open, resize or check the picture beyond confirming the file exists, so keep it under about 1600 pixels wide yourself.

## Taking them

- A phone is fine. Landscape, and fill the frame with the boy.
- Photograph a coach or one boy, not the group. One person, plain background.
- Shoot the first step and the stop from the side, because the fault is the body position. Shoot the arms and the landing from the front, because the fault is the arms crossing the body and the knees falling in.
- Get written permission from a parent before photographing any boy, and keep the photos in this repository only.
