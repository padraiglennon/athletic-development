# Architecture decision records

One file for each decision that shapes how this repository is built. A record says what the problem was, what was decided, and what the decision costs. A record is never rewritten after it reaches Done. A later record supersedes it instead.

Status runs `Draft`, then `Accepted`, then `Done`. A record can also end as `Rejected` or `Superseded by ADR-NNN`.
